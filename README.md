# Threefrogs Superweb

Website reservasi Threefrogs dengan fokus awal pada reservasi meja Mahjong.

## Fitur yang sudah ada

- Login / Register user
- Reservasi meja Mahjong per store, meja, tanggal, dan slot jam
- Hold slot saat booking dibuat
- Upload bukti pembayaran manual
- Admin melihat dan mengonfirmasi bukti pembayaran
- Cancel booking oleh user / admin
- Dashboard admin dasar

## Tech Stack

- Next.js
- TypeScript
- Prisma
- PostgreSQL
- NextAuth / Auth
- Cloudinary
- Tailwind CSS

## Jam Operasional

Reservasi aktif dari jam 11.00 sampai 22.00.
